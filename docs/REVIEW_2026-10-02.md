Reviewed the repository changes from the Paris calendar day of 2 October through
main commit `f4d983e35bfadb1001d7c7d59bad47917c6d940b`, including Claude's changes
merged just after midnight. This is a code/history/CI review, not a live validation
of every external provider or the operational datasets.

## Analytical limits to preserve

An AI-assessed exchange brand remains a hypothesis, not sourced ownership or a
calibrated probability. Source labels and AI leads remain distinguishable. `[GK]`
in Custom Intelligence identifies model knowledge; it is not an independently
retrieved source. Archive selection/deletion and consolidation are data-affecting
changes: passing unit tests does not establish that every merged/deleted incident
was analytically appropriate. Those records still require sampling against sources.

registry, feed, per-analyst reviewed state, keyword alerts, collection status and
an external Tor collector. It uses the existing ReportGate binding. Optional
acquisition keeps original files on the collector; it does not publish evidence.

none was accessed. No real-time monitoring is active yet.
